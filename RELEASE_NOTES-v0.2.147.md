# PulseStudio v0.2.147

A small rounded rectangular tab for the Mini transparency slider.

- Pale aqua fill and a fine neutral border, adapted to Light and Dark themes.
- Existing 58 x 18 slider size, position, 0–75% range and horizontal travel retained.
- Taller invisible thumb grab area; the visible tab stays only 9 x 7 pixels.
- Native smooth dragging, track clicks, immediate percentage updates and
  keyboard adjustment remain available without moving the application window.
- Pointer hover, click and drag show no halo, glow or input highlight rectangle.
  Keyboard focus changes only the small tab's neutral border.
- Recording, audio processing, transcription, Playback, updates, analytics,
  launchers and Mac/Windows publishing scripts are unchanged.
