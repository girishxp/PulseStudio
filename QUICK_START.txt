PulseStudio 0.2.144 — one shared folder for Mac and Windows
=========================================================

1. Extract the complete ZIP into a writable location.
2. Open the extracted PulseStudio folder.
3. Mac: double-click PulseStudio.app.
   Windows: double-click Start PulseStudio - Windows.bat.

Both launchers are in this SAME folder. Keep the entire folder together when
moving it or sharing it. No Terminal commands are needed.

The included application components are ready for Apple silicon Mac and
64-bit Windows. Apple silicon Mac first launch unpacks its bundled runtime
locally, without a setup download. Windows launches its included executable
directly; no Node installation, dependency download, or build is needed.
Before Mac launch, v0.2.144 prepares the physical host as Pulse Studio.app,
with an Electron.app compatibility link to the same executable and bundle ID.
Quit an older PulseStudio instance completely before opening the updated app.
A running host is never moved; the launcher asks you to quit and reopen if needed.
No host re-signing or permission reset is performed. Existing PulseStudio
settings, recordings and application data are retained.

Intel Mac remains supported through the launcher's bounded first-time setup.
Windows ARM uses x64 emulation and needs Windows 11 x64 application support.

Full and Mini View
------------------
The Classic Mac interface keeps the existing recording, playback, audio, AI,
privacy, and diagnostic options. Full View keeps its complete recording setup
and Quiet Studio Playback library; there is no transparency control in Full View.
New installs use Light appearance; your saved light/dark choice is kept on upgrade.

Choose the pastel blue Open Mini Controller action in Full View to keep the
recording controls on screen while you work. Mini View keeps the compact 262 x 84
content layout, with balanced icons, small side insets, and Classic Mac styling.

In Mini View, choose the Video + Audio or Audio Only icon-only selector before
starting. Hover briefly for the mode name and selection state.
During recording, the small mode icon beside the recording status confirms
whether you are recording Video + Audio or Audio Only.
The pastel blue Start/Stop action, Pause, Bookmark, and microphone controls
work as before. Start/Stop stays the same size when hovered. Classic Mini uses
lighter neutral gray, pastel blue, and mint surfaces.
Use Full View to return to the complete setup or playback library.

When adding a bookmark during Mini recording, you have 3 seconds to begin
typing optional marker text (previously 1 second). Starting to type keeps the
entry open. Choose Save or press Enter to save; skip the text to keep the
default bookmark.

Drag Mini View's small transparency bar from 0% to 75%, or focus it and use
the arrow keys. 0% is opaque; 75% transparency leaves 25% opacity. The saved
value affects only Mini View. The bar changes transparency without moving
the window. Full View always stays opaque.

Hover briefly over an icon for a short tooltip. Mini tooltips appear outside
the controller so they do not cover the recording information or buttons.

Quiet Studio Playback
--------------------
Open Playback and choose a recording from the library on the left. The player,
waveform, transport, bookmarks, snapshots, CC, volume, speed, and fullscreen
stay in the center. Related file and export actions are grouped beside the
player. Search, filters, categories, favorites, rename, Trash, and batch
selection remain available in the library. Open an action group for the
less-frequent controls without leaving the recording. The recording-row More
menu gives category, rename and Trash their own readable rows; play and favorite
remain directly beside each recording.

Use the tools inspector on the right:
- Transcript: views, search and exports, with speaker corrections in speaker view.
- Insights: chapters, meeting notes, and action items.
- Trim & cuts: export between two bookmarks, precision trim, and multiple cuts.
- Timeline: bookmark and chapter navigation.
Export between bookmarks: choose a saved start and end bookmark, then Clip
(MP4), Audio (M4A), TXT transcript, or SRT transcript, and choose Export interval.
Only that interval is saved. Audio-only recordings offer Audio, TXT and SRT.
If a transcript sentence crosses a marker or lacks usable timings, PulseStudio
transcribes just the selected audio; SRT times start on the exported clip timeline.

The recording-type/favorites filter remains on one row. Open Sort & filter
for category choices and all eight date, duration, name and file-size sorts.
The sort choice is remembered; Previous/Next follow that order. Drag the
full-height divider between the library and player to resize them.
In a narrower window, these tools stack below the player and the Playback
workspace stays within the window so its edge controls remain visible.
Recording setup stays in Record, and Mini stays a compact recording controller.

Meeting audio and microphone cleanup
-----------------------------------
Choose computer or application audio for the meeting. Turn on the microphone
if you want to include your own voice. Whenever the microphone is enabled,
PulseStudio automatically requests whole-system speaker echo cancellation
only when that capability is advertised, then verifies that it was applied.
If unavailable, it uses the available browser cancellation path. Echo handling
works independently of the Computer Audio toggle; no separate setting is needed.

Off, Standard, Enhanced voice, and Strong remain under
Record > Recording setup > Noise removal. Enhanced voice is recommended for
normal rooms; use Strong for unusually loud fan or air noise. There is no new
Playback noise-preset selector. Results depend on your
microphone, output device, speaker volume, and room. Headphones help prevent
speaker sound from entering the microphone. If you only need the meeting
audio, leave PulseStudio's microphone off; this does not mute your meeting app.

Available source microphone, cleaned microphone, and unmixed computer-audio
reference tracks stay locally in the hidden .pulsestudio-audio-sources folder
beside the saved recording. Only captured sources are kept. Companion tracks
follow rename, Trash, and recovery. Microphone/system audio is not uploaded.

First opening on Mac
--------------------
The Mac launcher is locally signed, without Apple notarization. If macOS blocks
its first opening, review it in System Settings > Privacy & Security.
If macOS asks to access the folder containing PulseStudio, allow that access
so it can read its shared application files.
v0.2.144 opens the physical Pulse Studio.app recording host and retains
Electron.app as a compatibility link to the same executable and bundle ID.
Its executable, signature and established PulseStudio data folder are retained.
A running host is never moved. Quit PulseStudio completely, then double-click
the updated PulseStudio.app launcher to finish preparing the Mac app name.
Sealed or unfamiliar runtime identities are left unchanged; the launcher shows
a preparation error if it cannot safely prepare the supplied host.
The Pearl Screen icon has a light pearl tile with a monitor and waveform.
Its Mac Dock symbol is a slightly stronger sky blue while idle. During recording,
the symbol and lower tile shading turn a more distinct aqua. Stopping or
cancelling restores blue. There is no red recording dot or flashing.
Windows uses the same Pearl Screen design as its application icon.
Grant Screen & System Audio Recording, Microphone, or Camera when needed to
the current host, which macOS may label Electron or Pulse Studio.
Quit and reopen PulseStudio if macOS requests it after a permission change.

Recordings, settings, analytics, and updates
------------------------------------------
New recordings, automatic transcripts, snapshots and default exports save in
Movies/PulseStudio on Mac or Videos/PulseStudio on Windows. Saved custom folders
are retained. Older recordings directly in Movies/Videos remain in Playback and
are not moved. Refreshed legacy transcripts save in the PulseStudio folder.

Fresh transcripts run automatically in the background. The app reuses its local
Whisper Small q8 model session to avoid loading it again for each recording.
The existing quality settings and recording priority are preserved. The first
model load and longer recordings can still take time. Your established
application-data folder, anonymous analytics configuration and saved backend
preference are retained. Analytics are on by default; the interface no longer
includes the analytics switch or launch reminder.

Both Mac and Windows check the public GitHub Latest release about 2.5 seconds
after launch and every 15 minutes while open. The in-app update popup offers
Update Now, Remind Me Later (24 hours), and Skip This Version. Checks and
installation wait for recording, saving, recovery and other active work to finish.
Update Now downloads, verifies and installs the shared ZIP, then reopens the app
when safe. A downloaded update can also offer Install & Reopen if work blocks
the initial restart. Internet access and a writable shared folder are needed;
users do not need GitHub login. Manual Check for updates is in About & Diagnostics.

Saving after Stop
-----------------
The app saves a stopped recording in the background. Record and Mini leave the
Saving phase once the media is ready, without waiting for library metadata to
refresh. A v0.2.141 fix removes an unnecessary full-recording audio decode
from audio-stream checks. These checks now read the media headers.
Final encoding, microphone cleanup and mixing can still take time, especially
for long recordings or a codec that requires conversion. The protected source
and recovery controls remain available if saving is interrupted. Automatic
transcription runs separately after the media is ready and does not delay the
saved-media result.

Publishing
----------
The owner can publish the same shared Mac/Windows ZIP from either OS:
Mac: double-click Publish PulseStudio.command.
Windows: double-click Publish PulseStudio - Windows.bat, keeping the companion
Publish PulseStudio - Windows.ps1 beside it in this same folder.

Each selects the newest matching ZIP beside the publisher or in Downloads,
then asks before commit, push and release creation. For this version, use
PulseStudio-cross-platform-v0.2.144.zip. One complete upload serves both Mac
and Windows users. Bundled runtimes are excluded from Git source commits.
A source push alone does not notify users: the newer semantic version tag and
matching ZIP must be published as a public Latest release. Nothing is published
by merely creating or extracting this package.

Both publisher helpers verify the active GitHub.com account and repository
write access directly. An unrelated enterprise account cannot redirect these
checks. Windows publishing requires Git for Windows and GitHub CLI installed
once, a signed-in GitHub.com account with write access, and a clean local main
branch. The PowerShell companion uses the Windows PowerShell supplied with
Windows 10/11. It does not change saved execution-policy settings.
See PUBLISHING.md for first-time owner setup and full-path examples.

Both accept --check-only (or --check). This is a read-only account/repository
access check: no ZIP unpacking, source edits, commit, push or release creation.

If launch fails
---------------
Mac: ~/Library/Logs/PulseStudio/launcher.log
Windows: %LOCALAPPDATA%\PulseStudio\logs\launcher.log
The graphical error dialog can open the log. Check that the complete folder
was extracted and is writable.

the library resize divider and fixes the saved-recording path display. It removes
the analytics switch/reminder and makes Pearl Screen recording colour clearer.

recording icon and adds Windows owner publishing next to the Mac publisher.
The idle icon and common launch folder are retained.

existing controls, icons and all recording and playback options.
The compact Mini controls, natural tooltips, Mini-only 0–75% transparency,
native controls, and shared prepared runtimes remain in place.
