Help

    

      
Record a screen or window

      
    
        
  1. Open Choose what to record and select a screen/window thumbnail.
    2. 
        
  2. Choose capture mode (screen/window, region, or all displays). In Recording Controls, select Video + Audio or Audio Only with one click and turn Webcam overlay on or off with the Apple-style switch. Microphone is enabled by default; use the mic icon beside Mic in Audio check for a quick mute/unmute before recording. Use Recording setup for audio/video quality and Recording options for filename, folder, countdown, cursor, and keystrokes. Microphone noise removal defaults to Enhanced voice with adaptive fan/air removal; use Strong when the fan or air flow is very loud.
    3. 
        
  3. Click Start recording. While recording, use Pause/Resume to temporarily stop capture and continue in the same output, or Stop recording to finish.
    4. 
        
  4. Video recordings save as MP4 and audio-only recordings save as M4A. New media saves to the selected Recording folder; the default is Movies on macOS or Videos on Windows.
    5. 
      

      
Readiness
Before recording, check the readiness strip above Recording Controls. It flags missing sources/regions, microphone/camera permissions, system-audio mode, and low recording-folder storage.

      
Audio-only recording
Choose Audio Only in the Recording Controls mode switch when you do not need video. Microphone and system audio continue to work, while video-only quality, FPS, cursor, keystroke, and webcam controls are disabled.

      
Filename templates
Use tokens {date}, {time}, {datetime}, {source}, {mode}, and {type}. The filename preview updates before recording and duplicate names are made unique automatically.

      
Webcam overlay
In Recording Controls, click the Webcam overlay switch to add or remove your camera with one click. When enabled, choose its camera, position, size, and circular or rounded shape directly beneath the switch.

      
Recording recovery
Active recording chunks and session metadata are journaled while recording. If the app exits before Stop is pressed, relaunch PulseStudio; the unfinished source stays protected and a compact Recover option appears. Recovery runs only when you choose Recover, can be stopped, and never blocks a new recording.

      
Selected-application audio
Choose a window thumbnail and select Selected application only under System audio. On macOS this uses ScreenCaptureKit. On supported 64-bit Windows builds it uses WASAPI process-loopback and captures the selected process plus child processes while excluding unrelated application audio.

      
Snapshots, bookmarks & editing
Use Snapshot while recording or the camera button in Playback. Use Bookmark while recording to mark an important moment. Playback shows bookmarks as timeline markers and provides Previous / Add / Delete / Next bookmark controls in the player toolbar. Single-click Add for a quick marker; double-click Add to type a short keyword or note directly above that marker. Named markers stay visible on the waveform, appear briefly over the video when playback reaches them, and can be double-clicked on the waveform to edit their text. Snapshots save beside recordings. For a simple trim, adjust the waveform-backed start/end handles and save a trimmed copy. To remove several unwanted sections, select each range, choose + Add selected range, then Save cleaned copy. All editing is non-destructive and the original recording is never overwritten. Export audio creates an M4A or MP3 audio-only copy of the selected recording.
Transcript search

      
After a recording is saved, its transcript is generated automatically. Search inside Transcript & subtitles; matches jump the video directly to that moment. Choose Raw (default), Speakers, or Timecoded. Speaker view uses local speaker detection and starts a new paragraph when the detected speaker changes. The transcript remains read-only, but you can copy, export, or turn on CC.

      
Library search
The Playback search field searches filenames, categories, and locally saved transcript text.

      
Chapters, meeting summary & action items
After transcription, Playback automatically creates local chapters, an extractive meeting summary, and likely action items from the transcript. Chapter, summary, and action-item timestamps jump directly to the matching moment. Meeting insights are cached locally and can be regenerated without an API key.

      
Keyboard shortcuts
Command/Ctrl+Alt+R Record/Stop · P Pause/Resume · B Bookmark · S Snapshot · M Full/Mini Controller. Press F1 or ? anytime for the complete shortcut reference. A shortcut may be unavailable if the operating system or another app already owns it.

      
Playback & subtitles

      
Open the Playback tab, choose a recorded clip, and turn on CC in the player when the transcript is ready. Use Rename to rename the MP4 and transcript files together. Use the small category selector beneath the Rename/Trash controls to organize clips. The trash icon moves the recording and the matching TXT transcript file (and any legacy SRT file) to your operating system Trash after confirmation, so they can be restored if needed.

      
Full View and Mini Controller

      
Use the Full / Mini switch in the title bar. Full View includes recording and Playback. Mini Controller is recording-only and keeps essential status and recording controls visible while staying out of the way. Recording setup, Recording options, and App & AI tools remain in Full View.

      
Window transparency

      
Use the ◐ icon in the title bar to choose 0%, 10%, 20%, 30%, or 50% transparency. The setting is remembered.

      
macOS permissions

      
If recording or microphone capture is blocked, open System Settings → Privacy & Security and enable Screen & System Audio Recording and Microphone access for the app/Terminal, then restart PulseStudio.

      
Windows permissions

      
If microphone capture is blocked, check Settings → Privacy & security → Microphone. System audio uses Windows loopback capture.

      
Diagnostic logs
PulseStudio keeps rotating troubleshooting logs in the child logs folder. Open About & Diagnostics → Open logs when you need to inspect or share a recording failure. The log contains runtime, capture, encoder, recovery, CPU/memory, and error details; it does not contain recorded audio or video content.
